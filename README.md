# Gestão da Campanha EA 2026

Aplicação web responsiva para acompanhamento da campanha, com API, autenticação por papéis, PostgreSQL e visualização somente leitura da planilha oficial.

Consulte o [índice completo da documentação](docs/README.md) para configurar, desenvolver, testar e publicar o projeto.
